## Screening projects

### Focusroom — Pomodoro timer

A responsive Pomodoro study timer built with HTML, CSS and vanilla JavaScript. Includes 25/5/15 focus cycles, a task list, saved progress, daily statistics, sound alerts, settings and dark mode.

- [Open the source folder](./focusroom-pomodoro/)
- [Read the setup guide](./focusroom-pomodoro/docs/START_HERE.md)
- [Read the interview guide](./focusroom-pomodoro/docs/INTERVIEW_GUIDE.md)

To try it locally, open `focusroom-pomodoro/index.html`. To publish with GitHub Pages, configure a deployment that serves the `focusroom-pomodoro/` folder, or publish its contents from the repository root.
