# Aditya — start here

## Try the project

1. Open `index.html` in Chrome or Edge.
2. Add a task. Try Start, Pause, Resume and Reset.
3. Refresh while paused and confirm the timer remains saved.
4. In Settings, temporarily set Focus to one minute. Check the automatic short break and daily count, then restore 25 / 5 / 15.
5. Try dark mode and distraction-free view.

## Publish with GitHub Pages

The app files are inside `focusroom-pomodoro/`. To publish a repository subfolder, GitHub Pages needs a deployment source that points to that folder. Follow the current GitHub Pages setup in the repository settings or move/copy the app files to the repository root if Pages is configured to publish only the root. Check the resulting site URL in an incognito window.
